# CloudForge

## Self-Healing, Multi-Environment AWS DevOps &
AI Incident Response Platform

CloudForge is a self-learning DevOps/SRE platform designed
to automate application deployment, monitoring, failure
detection, incident analysis, recovery, and rollback on AWS.

The project follows the lifecycle:

Deploy → Observe → Detect → Analyze → Recover → Verify → Measure

The platform will use infrastructure as code, CI/CD,
containerization, AWS monitoring, automated recovery,
chaos testing, load testing, and AI-assisted incident analysis.

All AWS infrastructure will be created temporarily for
learning and testing purposes and destroyed after experiments
to minimize unnecessary cloud costs.
